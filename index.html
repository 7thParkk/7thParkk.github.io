Research Interests

My research goal is to design practical and dependable techniques for discovering, understanding, and repairing security vulnerabilities in real software systems. Current directions include:

Vulnerability Detection and Repair

Automated techniques for identifying security vulnerabilities, explaining their root causes, and generating reliable repairs for affected code.

Security Patch Detection

Methods for recognizing whether code changes are security-related, analyzing patch intent, and connecting patches with vulnerability behavior.

Security Patch Generation

Patch synthesis and validation workflows that aim to produce correct, minimal, and security-preserving fixes for vulnerable programs.
